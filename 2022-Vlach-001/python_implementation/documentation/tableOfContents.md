Epidemic Network
# Documentation – Python implementation
## Table of contents

- [`epidemicNetwork_v01.py`](../epidemicNetwork_v01.py): Main module file implementing the `EpidemicModel` class and visualisation functions (`plot_model`, `plot_histograms`).

- [`demonstration.ipynb`](../demonstration.ipynb): Jupyter Notebook demonstrating how to initialise and run the epidemic model, produce the spatial disease map, and generate the simulation results dashboard, replicating the original NetLogo procedures.

- Output examples:
  - [`plot_model.png`](plot_model.png): Spatial settlement map with disease stage colours and recent transmission links, plus time-series plots of epidemic stages, population outcomes, and daily contacts/transmissions (replicates the NetLogo interface).
  - [`plot_histograms.png`](plot_histograms.png): Dashboard of 10 simulation-result distributions (link lengths, degree, household size, transmission probabilities, stage durations, and terminal-event timing).
